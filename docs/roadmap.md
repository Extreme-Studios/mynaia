# Roadmap Naya Virtual Girl

| Milestone | Output | Status |
| --- | --- | --- |
| 1 — Character Foundation + Architecture | Character bible, system prompt, rancangan UI/memori/integrasi, konfigurasi contoh, skenario dan acceptance, skeleton statis. | Dikerjakan di folder ini. |
| 2 — Tavus Free Realtime Avatar Proof of Concept | PAL Tavus-hosted dengan stock Face Anna, sesi video/mic nyata, uji latensi, interupsi, reconnect, dan kualitas avatar. | Implementasi lokal selesai; live test menunggu `TAVUS_API_KEY`. |
| 3 — LLM + Voice + Persona Integration | Evaluasi suara Bahasa Indonesia, kualitas persona, dan opsi LLM eksternal melalui adapter/gateway bila diperlukan dan disetujui. | Belum dikerjakan. |
| 4 — Memory System + User Profile | Persetujuan, penyimpanan preferensi ringan, tampilan/koreksi/hapus memori, dan pengujian privasi. | Belum dikerjakan. |
| 5 — MVP Application | UI responsive video call, backend sesi, autentikasi dasar, pengaturan, serta penanganan jaringan dan perangkat. | Belum dikerjakan. |
| 6 — Safety, Testing, Pilot Release | Uji keselamatan, aksesibilitas, perangkat nyata, retensi data, biaya, dan pilot terbatas setelah persetujuan. | Belum dikerjakan. |

Tidak ada pembelian, pembuatan custom Face, atau deployment production dalam Milestone 1.
